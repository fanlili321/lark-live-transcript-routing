# 直播文字稿整理 Skill 使用指南

一句话说明：AI 自动识别直播文字稿来源 → 自主整理文字稿（分段、去口误、术语规范、年份补全）→ 自动匹配并插入 PPT 配图 → 私聊知会执行人。全程 AI 自主完成整理，不再需要人工过一遍。

> 这是给人看的使用说明。AI 执行时读的是 [`SKILL.md`](SKILL.md) 和 `references/` 下的规则文件，两边内容是同步的。

## 一、怎么触发

两条路径，走哪条取决于直播类型：

1. **普通期数**：AI 实时监听"226课程群"，王磊在群里发妙记链接后自动触发，不需要人工介入。
2. **高净值客户专享直播**：王磊是私发链接（AI 纪要文档），不在群里，所以需要执行人把这个链接发给 AI，说明"这是第几期高净值直播的文字稿"，触发下一步。

两条路径后续的整理、配图、命名规则不同，识别来源不同，其余步骤走的是同一套流程。

## 二、完整流程（6 步概览）

1. **识别消息**：判断是普通期数还是高净值，拿到王磊发的"文字记录"（不是妙记标记链接本身）。
2. **匹配正式标题**：妙记/AI纪要的标题是非正式的，正式标题要去对应的 PPT 共享文件夹里找（普通期数、高净值、对外演讲/线下活动，一共三个文件夹，AI 会自己按期数/日期查）。
3. **创建归档文件夹 + 文档**：直接用最终标题创建，不再有"先建个 `_原文` 中间态、整理完再改名"这一步。
4. **AI 自主整理文字稿**：分段、错别字校对、年份补全（两位数补全成四位）、语气词删除（呢/啊/诶/哈/哎等）、问答小标题拆分并统计字数。
5. **匹配 PPT 并插入配图**：按讲解部分的 PPT 页码顺序，为每张图找到文字稿里精确的引入句再插入，不是随便找个关键词命中的地方。
6. **私聊执行人一条完成通知**：告诉执行人（谁在用这个 skill，就通知谁，不是固定某个人）整理完成、文件夹和文档链接在哪。**这一步不进任何群、不回填排期表**——这两件事挪到了后面"复核反馈处理完成"之后才做，见第四节。

## 三、三种类型的命名规则

| 类型 | 归档文件夹命名 | 文档标题命名 | 示例 |
|---|---|---|---|
| 普通期数 | `<期数> <正式标题>` | `<正式标题>｜螺丝钉专属直播课第<期数>期` | 文件夹 `466 A500、A50指数，该怎么投资？`；文档 `A500、A50指数，该怎么投资？｜螺丝钉专属直播课第466期` |
| 高净值客户专享直播 | `YYYYMMDD 第{N}期 <正式标题>（高净值客户尊享直播）` | `第{N}期-{标题}（高净值客户专享直播课）` | 文件夹 `20260806 第23期 牛市中后期，私募FOF是如何止盈的？（高净值客户尊享直播）` |
| 对外演讲/线下活动 | 与文档标题完全相同 | `<正式标题>｜<场次说明>` | `红利指数基金，该如何投资？｜20260530大众场活动（中信出版社读者见面会）` |

## 四、如果有人在文档里留了批注（复核反馈处理）

同事/领导在整理好的文档里留批注，或者聊天里发反馈（文字、截图都算），走这个流程：

1. **直接在原文档上改，不建备份副本**——批注是锚定在具体 block 上的，改原文档才能保留对应关系；改完文件夹里只有一个文件，就是最终版本。
2. 逐条读批注定位问题，也结合聊天里说的但批注没写清楚的点。
3. 只改内容，不回复/不标记已解决/不删批注（除非明确要求）。
4. 用定点编辑（找文字替换、移动图片位置），不整篇重写，避免批注的引用关系丢失。
5. 所有文字改完后最后统一重算字数。
6. **改完之后，等对方明确说"没问题/OK"了，才算这一轮结束**——不能自己觉得改完了就完事。
7. **对方确认没问题之后**（不是改完就做，是确认完才做）：
   - 去"排期与流程文档"里对应期数那一行，把整理好的文档链接回填到"链接"列。
   - 在"内容小分队"群里艾特范丽丽，告诉她这期可以复核了。

## 五、使用小技巧 / 常踩的坑

这些是几轮真实复核里踩过的坑，提前知道能少走弯路：

- **语气词删除要一次性全量扫描**：呢/啊/诶/哈/哎 都要查一遍，不能只改被点名的那一两个——这个问题在不同文档上反复出现过三次，每次都是只改了被指出的那个字，漏了同类的其他字。
- **年份补全的"复合列表"陷阱**：像"22、23、24"这种连续列举、只有最后一个数带"年"字的写法，容易漏改成年份（该是"2022、2023、2024"）。这种不能靠读的时候留意，要专门跑一遍正则扫描（找"数字+顿号+…+数字+年"的模式）逐个核对。
- **PPT 配图要找精确的"引入句"**：不能靠数字或关键词随便命中一个段落就插进去，要找到讲者真正开始讲这张图的那句话（比如"这个数据里边有几个比较典型的特征"）。
- **两张图之间必须有真实文字，绝对不能挨在一起插**：如果两张图匹配到了同一段文字，说明还没找准，要继续拆分定位，不能凑合放在同一个位置。
- **字数统计必须用官方脚本 `doc_word_stat.py` 的 `word_count`**：不能用字符长度（比如 Python 的 `len()`）估算，两者差异能到 5%-15%，飞书界面看到的数字对不上。
- **产品/工具/小程序名称，以 PPT 上写的为准**：王磊口播时偶尔会把同一个产品名说错（比如"今天几星"说成"今天基金"），这种不是错别字清单能穷举的，要拿 PPT 上的名称去核对全文所有提到的地方。
- **高净值文档用 markdown 格式抓取时会留下转义字符**：常见的是"~"被转成`\~`，整理完成后要专门查一遍，别把字面反斜杠带进最终文档。
